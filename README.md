# DS4MFG Student Statistics Cheatsheet

A single-page student reference for DS4MFG. It is designed for GitHub Pages and can be served directly from the repository root.

## What is inside

- `index.html` — the full interactive cheatsheet.
- `.nojekyll` — keeps GitHub Pages from applying Jekyll processing.

## Publish with GitHub Pages

1. Create a public repository on GitHub, for example `onesnowball/ds4mfg`.
2. Push these files to the repository's `main` branch.
3. In GitHub, open **Settings → Pages**.
4. Set **Source** to `Deploy from a branch`, then choose `main` and `/root`.

The site will publish at `https://onesnowball.github.io/ds4mfg/`.
